## Assumptions

- Screenplay timestamps are aligned with the video timeline.
- A promo may contain one continuous segment or multiple validated segments.
- A human editor remains the final judge of social appeal.
- The submission uses deterministic heuristics for the complete 50 episode run. Model judgments are optional and can be enabled for additional review.

## Confidentiality

Do not upload episode screenplay files to a public repository or share them in the solution document. The raw output package contains only generated metrics, export tables without dialogue, and run evidence needed to reproduce the checks.
